# Project 4 – Data Visualization

## Description

This project focuses on creating an interactive **E-Commerce Data Visualization Dashboard** using Power BI Desktop.

The goal of the project is to transform the cleaned e-commerce dataset into meaningful visualizations that clearly communicate sales performance, product trends, customer/order information, and other important business insights.

## Dataset

The dashboard is created using the cleaned dataset generated in Project 1:

Cleaned_Dataset.csv

The dataset contains information such as:

* OrderID
* Date
* CustomerID
* Product
* Quantity
* UnitPrice
* PaymentMethod
* OrderStatus
* ReferralSource
* TotalPrice

## Dashboard Components

The Power BI dashboard includes the following visualizations and analysis:

### KPI Cards

Key performance indicators are displayed using cards:

* Total Orders
* Total Revenue
* Average Order Value
* Total Quantity Sold

### Top Selling Products

A bar chart is used to identify products with the highest quantity of units sold.

### Revenue by Product

A column chart is used to compare the revenue generated by different products.

### Referral Source Performance

A bar chart is used to analyze revenue generated through different referral sources.

### Payment Method Analysis

A donut chart is used to show the distribution of orders across different payment methods.

### Order Status Analysis

A donut chart is used to visualize the distribution of order statuses.

### Monthly Sales Trend

A line chart is used to display changes in revenue over time and identify sales trends.

### Product Filter

A slicer is included to allow users to filter the dashboard by product.

### Key Insights

A text box is included to highlight important observations and insights obtained from the dashboard.

## DAX Measures

The dashboard uses DAX measures to calculate important KPIs.

Examples include:

Total Orders = COUNT('Cleaned_Dataset'[OrderID])

Total Revenue = SUM('Cleaned_Dataset'[TotalPrice])

Average Order Value = AVERAGE('Cleaned_Dataset'[TotalPrice])


Total Quantity = SUM('Cleaned_Dataset'[Quantity])

These measures are used throughout the dashboard to provide dynamic and interactive results.

## Key Insights

The dashboard helps analyze:

* Overall order volume
* Total revenue generated
* Average order value
* Product sales performance
* Revenue by product
* Payment method usage
* Order status distribution
* Referral source performance
* Monthly revenue trends

## How to Run

### 1. Install Power BI Desktop

Install Microsoft Power BI Desktop on your computer.

### 2. Open the Project

Open the Power BI project/report file.

### 3. Load the Dataset

Make sure `Cleaned_Dataset.csv` is available and connected to the Power BI report.

### 4. Refresh the Data

In Power BI Desktop, use:

**Home → Refresh**

to update the dashboard with the latest dataset.

### 5. Explore the Dashboard

Use the charts, KPI cards, and product slicer to interact with the dashboard and explore different aspects of the e-commerce data.
